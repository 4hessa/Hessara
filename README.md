# Hessara

منصة عربية لتقييم النماذج ومقارنتها، مبنية بـ TypeScript وReact وVinext وCloudflare Workers/D1.

## ما يعمل الآن

- 240 مهمة مرجعية في ست فئات: فهم البرمجة، المنطق، التحليل، الاسترجاع، اتباع التعليمات، والسياق الطويل.
- قسم النماذج اللغوية يضم 30 نموذجًا، مع مقارنة المواصفات والربط الجماعي عبر OpenRouter وإضافة نماذج أخرى.
- مقارنة حتى 30 نموذجًا في تجربة واحدة، من OpenAI وAnthropic وGoogle Gemini وOpenRouter وNVIDIA بمفاتيح المستخدم الخاصة.
- مسار ربط أربعة نماذج متاحة للتقييم المجاني لدى NVIDIA، مع التحقق من الإتاحة والمفتاح قبل الحفظ. الوصول خاضع لحصة حساب المستخدم وشروط المزود، وليس استدلالًا مجانيًا غير محدود.
- دليل الأدوات يضم 317 أداة فعلية في 11 مجالًا، مع البحث والتصفية والمفضلة وروابط GitHub المباشرة.
- قسم «وكلاء خارقون» يضم 19 مشروعًا بروابط مباشرة، مع تجربة قرار مُهيكل تقترح فئة اختبار عبر jev بمفتاح المستخدم أو خادم Laya الذي يربطه بنفسه. يظل OpenClaw وأمثاله مشاريع مستقلة تحتاج إعدادًا خاصًا.
- قسم «كيف تعمل المنصة» يشرح الخدمات والمنهجية والحدود، وتكامل Paperclip لتصدير أو إرسال مسودات مراجعة النتائج.
- تفاصيل الأدلة الجديدة بالعربية والإنجليزية.
- تخزين المفاتيح مشفّرة باستخدام AES-256-GCM؛ لا تعاد المفاتيح أو نصوصها المشفرة إلى المتصفح.
- تجارب محفوظة، إيقاف مؤقت واستئناف، ومنع ازدواج التنفيذ المتزامن للتجربة نفسها.
- متوسط جودة متوازن بين الفئات، p50 وp95، ثبات الإجابة، الأخطاء، الرموز والتكلفة التقديرية.
- مراجعة كل نتيجة وإجابتها المرجعية وتصدير JSON وCSV.
- العربية افتراضيًا و12 لغة إضافية؛ الأردية والفارسية والعربية تدعم اتجاه RTL.
- هوية لؤلؤية ووردية هادئة بأسلوب Ethereal Haze من طبقات CSS بدل الصور. الاسم أصغر 10% والشعار أصغر 5% من النسخة السابقة، ويبقى الشعار ثابتًا. خط DM Serif Display للاسم وIBM Plex Sans Arabic للعربية. مؤشر مخصص وحلقة تتبع خفيفة، مع احترام تقليل الحركة. تظهر نتائج التجربة المحفوظة مباشرة.
- المحاكاة مستقلة عن التقييم الفعلي، بأسماء افتراضية وبيانات موسومة بوضوح.

## التشغيل المحلي

المتطلبات: Node.js 24 أو أحدث وnpm.

```sh
npm ci
cp .env.example .env
```

أنشئ مفتاح تشفير عشوائيًا من 32 بايت وأضفه إلى `HESSARA_ENCRYPTION_KEY` في `.env`. لا ترفع الملف إلى GitHub ولا تغيّر هذا المفتاح بعد حفظ مفاتيح النماذج إلا ضمن عملية ترحيل مدروسة؛ تغييره يمنع فك تشفير المفاتيح القديمة.

```sh
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
npm run build
```

طبّق ترحيلات D1 المحلية مرة واحدة وبالترتيب:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_flat_living_mummy.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_funny_shiva.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_giant_ultron.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0003_decision_usage.sql
npm run dev
```

افتح العنوان الذي يطبعه الخادم، ثم استخدم زر تسجيل الدخول. في المعاينة المحلية فقط، يتولى المسار `/signin-with-chatgpt?return_to=/` إنشاء جلسة اختبار. الإنتاج يعتمد على تسجيل الدخول الذي توفره منصة Sites؛ لا يوجد تجاوز لتسجيل الدخول في تطبيق الإنتاج.

يمكن إدخال اتصال النموذج من واجهة «النماذج والربط»، أو ضبط المفتاح ومعرّف النموذج ومتغيرات الأسعار في بيئة الخادم. لا توجد معرّفات تجارية أو أسعار مفترضة مثبتة في الكود.

على Windows، إذا تعذر تشغيل npm بسبب غلاف النظام، استخدم مسار `npm-cli.js` الصحيح في تثبيت Node. ترحيلات Drizzle التي تم نشرها لا تُعدّل؛ أضف ترحيلات جديدة.

## التشغيل المستضاف

- يحتوي `.openai/hosting.json` على هوية الموقع وربط `DB` المنطقي فقط.
- تُضبط `HESSARA_ENCRYPTION_KEY` وغيرها من الأسرار في إعدادات بيئة الاستضافة، ولا تُضمَّن في الأرشيف.
- تُطبّق ملفات `drizzle/*.sql` أثناء النشر.
- جميع الاستعلامات مرتبطة بهوية المستخدم، وتُرفض الطلبات غير المسجلة وطلبات التعديل من أصل مختلف.
- الموقع متاح للعامة؛ حفظ التجارب والمفاتيح وتشغيلها يتطلب تسجيل الدخول. النتائج وروابط النماذج معزولة لكل حساب.

## منهجية القياس

كل فئة تضم أربعة قوالب، ولكل قالب عشر حالات ثابتة. يتلقى كل نموذج المهام نفسها. تستمر نصوص الاختبار بالإنجليزية عند تغيير لغة الواجهة للحفاظ على المقارنة نفسها.

**الجودة:** متوسط نسب النجاح للفئات المختبرة بأوزان متساوية؛ الأخطاء والمهل والإجابات غير المطابقة تساوي صفرًا. لا تُعتمد النتائج الجزئية كترتيب نهائي.

**السرعة:** مدة الطلب الكامل من الخادم حتى اكتمال الاستجابة، لا زمن أول رمز. تُحسب المئينات بطريقة nearest rank؛ المدة المفقودة لا تتحول إلى صفر.

**الثبات:** نسبة المهام التي أعادت النص نفسه بعد حذف الفراغات الطرفية في التكرارات. لا يظهر عند تكرار واحد، ولا يثبت صحة الإجابة.

**الرموز:** بيانات المزود، مع احتساب رموز التفكير ضمن الإخراج حين يوفرها. إذا كانت بيانات إحدى المحاولات ناقصة، يظهر المجموع كغير متاح.

**التكلفة:** تقدير على أساس سعر الإدخال والإخراج الذي يدخله المستخدم، بالدولار لكل مليون رمز. الاستخدام المخزّن مؤقتًا لا يُسعَّر كتخمين؛ تظهر التكلفة غير متاحة عندما لا تتوفر بيانات كافية. ليست هذه فاتورة.

**الحدود:** هذه مجموعة صناعية أولية، لا معيارًا شاملًا لجميع الاستخدامات. البرمجة هنا فهم الكود وتتبع المخرجات، لا تنفيذ كود مولَّد. الاسترجاع ضمن مستندات مُرفقة وليس بحث الويب. السياق الطويل استخراج من 400–1,600 سجل، لا وكيلًا ذاتيًّا طويل العمل. موارد GPU وRAM والطاقة غير متاحة من موصلات API هذه.

## تنفيذ التجارب وسلامة النتائج

- يدفع المتصفح دفعات التنفيذ؛ أبقِ الصفحة مفتوحة. يمكن إعادة فتح التجربة والاستئناف من النتائج المحفوظة.
- عدد الاستدعاءات المتزامنة ثلاثة للتقييم الفعلي و24 للمحاكاة.
- حد الاستجابة 512 رمزًا وحد المهلة 55 ثانية للمزودين الأصليين؛ تستخدم إنفيديا 4096 رمزًا و90 ثانية مع إعداد التفكير المنخفض لكيمي. تُسجّل السياسة لكل نموذج داخل التقرير. راجع [دليل إنفيديا](docs/NVIDIA.md) للتفاصيل.
- لكل تجربة قفل قاعدة بيانات مؤقت. تُحفظ الحالات المحجوزة قبل أي اتصال خارجي.
- الطلبات التي انقطعت نتيجتها تُسجّل `interrupted_unknown_outcome` ولا يعاد إرسالها مدفوعًا تلقائيًا.
- تُربط كتابة النتائج بملكية القفل؛ انتظار جميع العمليات يمنع تعديل نتيجة مكتملة من دفعة سابقة.
- لا يُنفّذ أي كود مولّد على خادم التطبيق.

## الاختبارات

```sh
npm test
node node_modules/typescript/bin/tsc --noEmit
node tests/local-api.mjs
```

اختبار API مقيد بـ localhost، ويستخدم محاكاة فقط دون استدعاء مزود مدفوع. ينشئ بيانات اختبار محلية واضحة الاسم؛ لا يمس قاعدة الإنتاج. يتحقق من الهوية والتحقق من المدخلات والأصل وحفظ الاتصالات والاستئناف والتزامن وإكمال 240 مهمة دون تكرار.

الاختبارات تغطي مراجع المهام، وصحة مخرجات قوالب JavaScript الموثوقة، وصرامة JSON، والقياسات الناقصة، والأوزان، وحتمية المحاكاة. لا يعني نجاحها أن موصلات المزودين اختُبرت بمفاتيح حية؛ يحتاج ذلك ربط حساب فعلي وتشغيل تجربة.

## بنية المشروع

```text
app/                 الواجهة ونقاط API
lib/benchmarks.ts    مولد المهام والمصحح وحساب المقاييس
lib/server.ts        الهوية والتخزين وموصلات المزودين
lib/vault.ts         تشفير مفاتيح المستخدمين
lib/locales/         ترجمات الواجهة
public/              الشعار والخطوط المحلية وتراخيصها
db/                  تعريف مخطط البيانات
drizzle/             ترحيلات قاعدة البيانات
tests/               اختبارات المحرك والتكامل
```
