# تكاملات Hessara

## وكلاء خارقون ومحركات القرار

يعرض القسم دليلًا موثقًا من 19 مشروعًا: محركا قرار مُهيكل ووسيط متوافق معهما، مساعدون شخصيون، أطر بناء وكلاء، ووكلاء متخصصون. يصل زر «المشروع الأصلي» إلى مستودع كل مشروع مباشرة. الإدراج في الدليل لا يعني أن Hessara يشغّل ذلك الوكيل أو يمنحه صلاحية على بيانات المستخدم.

يوفر القسم تجربة عملية لاقتراح إحدى فئات الاختبار الست عبر محركَي قرار منفصلين عن نماذج المحادثة:

- **jev:** يرسل الخادم وصف المهمة إلى واجهة TypeSafe AI الرسمية `POST https://api.typesafe.ai/v1/systemone` مع مفتاح يدخله المستخدم. لا يُحفظ المفتاح أو نص الوصف. مصدر العقد: https://docs.typesafe.ai/introduction/quickstart
- **Laya Decision:** يعمل على خادم مستقل يهيئه المستخدم وفق مشروع Laya الأصلي. يطلب Hessara مسار `HTTPS /v1/systemone` فقط، مع مفتاح اختياري إن كان الخادم محميًا. Laya غير مستضاف داخل Worker. المصدر: https://github.com/NandhaKishorM/laya

يُعاد للمستخدم اسم الفئة وثقة المحرك إن وردت، ثم يختار بنفسه بدء تجربة عليها. لا يقرر المحرك تغيير نموذج الإنتاج أو تشغيل وكيل. تعريف الثقة مختلف بين jev وLaya، لذلك لا يقارن Hessara النسب بينهما أو يستعمل عتبة مشتركة. يعتمد نجاح الاتصال على مفتاح المستخدم، وتوافر المزود، وخادم Laya إن اختاره؛ لم تُنفّذ طلبات حية مدفوعة أثناء التطوير.

طلب الربط محدود الحجم، والرد محدود الحجم والوقت، مع منع إعادة التوجيه وحصر وجهة Laya في عنوان HTTPS محدد المسار واسم نطاق غير محلي حسب الفحص النصي. لكل حساب 60 محاولة اتصال يوميًا. تُرفض طلبات التعديل من أصل آخر حتى عند غياب ترويسة Origin، ولا تُخزّن ردود الخطأ مؤقتًا. هذه مراجعة مركزة تسترشد بـ https://github.com/cloudflare/security-audit-skill وليست تدقيقًا أمنيًا شاملًا أو اختبار اختراق.

**OpenClaw** والمساعدون المشابهون روابط لمشاريع مستقلة تتطلب إعدادًا شخصيًا. لا تُشغَّل بوابة OpenClaw مشتركة بين زوار Hessara؛ هذا يتفق مع نموذج الثقة المعلن في مستودعه https://github.com/openclaw/openclaw/security .

## LLMs وOpenRouter

يعرض الدليل 30 معرّف نموذج تحقّقنا منها عبر `GET https://openrouter.ai/api/v1/models` في 27 سبتمبر 2026. الرابط في كل نموذج يصل إلى مصدر مواصفاته. المعروض مواصفات وأسعار مرجعية، وليس نتائج تقييم أو ترتيب جودة.

اختيار النماذج ثم ربطها يحفظ ملفات اتصال مشفّرة، ويحدّث أسعارها من كتالوج المزوّد. لا يُرسل اختبار مدفوع حتى يبدأ المستخدم التجربة. يدعم الموصل `POST /api/v1/chat/completions`، ويحفظ معرف النموذج المطلوب والمستخدم وبيانات الاستخدام. يتطلب كل نموذج إتاحة فعلية ورصيدًا عند الحاجة؛ لم تُنفّذ اختبارات بمفتاح حي أثناء التطوير.

يمكن إضافة نموذج غير مدرج من نافذة «إضافة نموذج آخر» باستخدام معرّف يدعمه أحد الموصلات. لا يعني ذلك دعم أي بروتوكول أو خادم محلي تلقائيًا. يدعم النظام 30 نموذجًا للتجربة و3 استدعاءات حية متزامنة، و100 ملف اتصال لكل مستخدم.

لتحديث أسعار ومواصفات القائمة دون تغيير اختيار النماذج:

```sh
node scripts/refresh-model-catalog.mjs
```

يتوقف السكربت عند حذف نموذج من المزوّد بدل استبداله بمعرّف تخميني. راجع الفرق ثم أعد البناء والنشر.

## Paperclip

المصدر: https://github.com/paperclipai/paperclip

وثائق إنشاء المهام: https://docs.paperclip.ing/reference/api/issues/

Paperclip خدمة Node.js وقاعدة PostgreSQL مستقلة؛ لم تُضمّن كتطبيق داخل Worker. يبني Hessara مسودة مهمة تحتوي على المقاييس الإجمالية وخطوات المراجعة، دون مفاتيح أو إجابات النماذج. تُنشأ بحالة `backlog` دون إسناد لوكيل أو تنفيذ تلقائي.

### ربط خادم مستضاف

اضبط الأسرار في بيئة الخادم، لا في ملفات المصدر:

- `PAPERCLIP_BASE_URL`: عنوان HTTPS لخادم Paperclip الخاص بك.
- `PAPERCLIP_COMPANY_ID`: معرّف مساحة عملك.
- `PAPERCLIP_API_KEY`: مفتاح يملك صلاحية إنشاء المهام في تلك المساحة.
- `PAPERCLIP_OWNER_ID`: معرّف مستخدم Hessara الوحيد المخوّل باستعمال هذا الاتصال. يمكن أخذه من حقل `owner` لتجربته في قاعدة البيانات. لا تُشارك صلاحية الاتصال بين مستخدمين تلقائيًا.

بعد اختيار تجربة، افتح Tools ثم تكامل Paperclip واضغط «إرسال مسودة مراجعة». تظهر وجهة الإرسال قبل الزر. يسجل Hessara محاولة الإرسال قبل طلب API ويمنع إرسال التجربة نفسها مرتين. إذا انقطعت الاستجابة تُوسم النتيجة غير معروفة ولا تُعاد المحاولة تلقائيًا؛ راجع Paperclip قبل أي إرسال يدوي.

### استخدام Paperclip محليًا

نزّل ملف المهمة من المنصة، ثم اضبط `PAPERCLIP_BASE_URL` و`PAPERCLIP_COMPANY_ID` و`PAPERCLIP_API_KEY` في بيئة الطرفية. يمكن لخادم loopback يعمل بوضع Paperclip المحلي الموثوق أن يستغني عن المفتاح. نفّذ:

```sh
node scripts/paperclip-import.mjs hessara-paperclip-issue.json
```

لا يثبّت السكربت أي خدمة ولا يشغّل وكيلًا؛ ينشئ مسودة واحدة في الوجهة المحددة. لا يكرر الطلب تلقائيًا. لم يُختبر الاتصال على خادم Paperclip فعلي لعدم توفر عنوان ومفتاح من المستخدم.

## دليل Tools

317 أداة ومستودعًا في 11 مجالًا، منتقاة من مستودعات GitHub العامة. لكل سجل رابط المصدر ووصف عربي وتاريخ تحقق وترخيص كما أعلنه المصدر. اخترنا برمجيات وأطر عمل ومجموعات تقييم، واستبعدنا التكرارات والقوائم العامة والدورات. وجود المستودع لا يضمن جودة برمجياته أو أمنها. لم ننسخ كود هذه الأدوات إلى المنصة، ولم نثبّتها تلقائيًا؛ الروابط تتيح الوصول إليها مباشرة.

المفضلة محلية في متصفح المستخدم. واجهة المنصة الأساسية تدعم 13 لغة، وتفاصيل الأدلة الجديدة متاحة بالعربية والإنجليزية؛ وصف المصدر الإنجليزي يبقى باللغة التي أعلنها مؤلف المستودع عندما لا يوفر الإنجليزية.
